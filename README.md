# CampusMate - Student Utility App

One Unified Platform for UIU students


## Features
- Lost and Found
- Campus Marketplace
- Study Help Forum
- AI Based Quiz System
- Freshers Corner (Frequently Asked Questions from Freshers)
- Tuition Fee payment reminder via Notification
- Tuition Fee Calculator
- CGPA Calculator and Planner

## Run in Test Mode
1. Install Flutter SDK - Follow the [official tutorial](https://docs.flutter.dev/install/manual)
2. Install Visual Studio Build Tools – Follow the [official tutorial]( https://docs.flutter.dev/platform-integration/windows/setup)
3. Clone this project 
`git clone https://github.com/runtimeghost/campusmate.git`
4. cd into the project folder
`cd campusmate`
5. Run in debug mode
`flutter run --debug`
